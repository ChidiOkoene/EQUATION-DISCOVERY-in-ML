# Results archive

All historical experiment artifacts are kept here (nothing deleted during the restructure). Paths mirror `experiments/`.

| Folder | Contents |
|--------|----------|
| `burgers/pidl/` | Burgers PiDL run — plots, `Pred.mat`, `Histories.mat`, `stdout.txt` |
| `burgers/pysr/` | PySR hall-of-fame CSVs/pickles and training-run logs |
| `industrial/pidl/term-library/` | Term-library experiment plots and matrices |
| `industrial/pidl/archive/` | Full set of industrial PiDL run folders (`output_*`, `new_output*`, …) |
| `industrial/pidl/misc/` | Leftover figures and recordings |

Start with `burgers/pidl/u_comparison_line.png` and `industrial/pidl/archive/new_output_2/` for a quick visual tour.

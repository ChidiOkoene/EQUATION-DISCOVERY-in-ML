# Datasets

| Folder | Description |
|--------|-------------|
| `burgers/` | Burgers PDE `.mat` / CSV inputs and a few public tabular samples used in early trials |
| `industrial/` | Clamping-force and SWE_VDC / ABSTCSVDC time-series CSVs used by PiDL EqD scripts |
| `reconstructed/` | Feature rows synthesized to match discovered formulas (`scripts/utils/data_reconstruct_mainX.py`) |

Point scripts and notebooks at these paths with relative imports from their new locations under `scripts/` and `notebooks/`.

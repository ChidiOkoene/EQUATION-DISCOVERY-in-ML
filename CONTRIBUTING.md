# Contributing

This repo is primarily a research showcase. When adding work:

1. Put **code** under `scripts/` or `notebooks/` by method (`pidl`, `pysindy`, `pysr`, `pinns`).
2. Put **datasets** under `data/` (`burgers`, `industrial`, or `reconstructed`).
3. Put **run outputs** under `results/` in a named folder — do not dump plots at the repo root.
4. Prefer **relative paths** into `data/` so experiments run on any machine.
5. Update the README gallery or “Explore by path” section if you add a headline result.
